# 控制台 UI 规范（v2）

> 适用：`shared/admin/` 这一份源码，同时服务 Hub 与 Full。效果图在 [`docs/ui-v2/mockups/`](./ui-v2/mockups/)，
> 打开 `.html` 即可看（`v2.css` 是参考样式，不是生产代码）。规范与效果图冲突时以本文为准。

## 1. 原则

1. **简约**：灰阶表面 + 一个主色（蓝）。主色只用于主按钮、选中态、链接；状态只用圆点颜色表达。
2. **列表负责找，弹框负责改**：列表行不展开、不折叠；点行打开弹框编辑。
3. **一个窗口做完一件事**：弹框内不做步骤导航；内容多时分节，次要项放进「高级设置」折叠。
4. **数值不写死**：尺寸、颜色、间距、圆角、字号全部来自 `app.css` 顶部 `:root` 的 token。本文只写 token 名和相对关系，不写像素值；JS 与 HTML 里不得出现尺寸数字。
5. **系统默认字体**：不使用等宽字体；数字列用 `font-variant-numeric: tabular-nums` 对齐。
6. **只用现有数据**：界面不得引入后端没有的字段。需要新字段，先改契约（见 `AGENTS.md` §5）。

## 2. Token（在 `app.css :root` 定义，一处定义）

| 类别 | Token | 说明 |
|---|---|---|
| 表面 | `--bg` `--surface` `--surface-2` `--hover` | 页面底、卡片/列表、弹框内次级底、悬停 |
| 线 | `--line` `--line-2` | 外框、内部分隔线（更浅） |
| 文字 | `--fg` `--fg-2` `--muted` `--faint` | 正文、次要、说明、禁用 |
| 主色 | `--accent` `--accent-soft` `--accent-fg` | 蓝（取 magpie 靛蓝）；soft 用于选中底色 |
| 状态 | `--ok` `--warn` `--err` `--off` | 只给圆点和极少量文字用 |
| 尺寸 | `--ctl-h` `--ctl-h-sm` `--r-ctl` `--r-box` `--r-dialog` | 控件高、紧凑控件高、控件圆角、容器圆角、弹框圆角 |
| 间距 | `--gap-1` … `--gap-6` | 一套等比间距，所有 margin / padding / gap 只取这些 |
| 字号 | `--fs-title` `--fs-body` `--fs-ctl` `--fs-note` | 页面标题、正文、控件、说明，共四档 |
| 布局 | `--page-max` `--dialog-w` `--dialog-w-wide` | 页面最大宽、弹框宽、宽弹框宽 |

暗色主题只覆盖颜色 token，不覆盖尺寸 token。删除旧的 `--khc-*` token，不保留别名。

## 3. 页面骨架

- **顶栏**：左侧品牌 + 端标识（Hub / Full，灰字）；中间分段导航；右侧配置版本、隐私遮罩、主题、退出。
- **导航**：Hub 为 节点 / 供应商 / 模型 / 统计 / 设置；Full 为 概览 / 供应商 / 模型 / 接入信息 / 设置。
- **页头**：标题 + 灰色计数摘要（如「12 个 · 22 把 Key · 19 把可用」）；右侧最多一个主按钮，其余为普通按钮。不写副标题。
- **工具条**（列表多于一屏时才出现）：搜索框 + 筛选芯片（全部 / 需要处理 / 已停用，带数量）。

## 4. 组件

### 4.1 列表行（全站唯一写法）

- 只能由一个生成函数 `listRow({ title, sub, status, count, logo?, onOpen })` 产生；其它地方不得手写 `.row`。T1 增加测试：除该函数外，源码中出现 `className = 'row` / `class="row` 即失败。
- 列固定为：**名称 + 次要信息** | **状态** | **计数** | **右箭头**。状态和计数列宽由 token 决定，所有页面对齐。
- 状态 = 圆点 + 一个词。次要信息一行，超长省略。出问题的行，次要信息直接写原因（`--err` 色文字）。
- 行可点，悬停变 `--hover`，没有展开态、没有 chevron 旋转。
- 分组：需要时用组标题行（如「需要处理 · 2 / 正常 · 9 / 已停用 · 1」），问题优先排序。

### 4.2 弹框（magpie 规范）

- 遮罩半透明加模糊；弹框居中，圆角 `--r-dialog`，宽 `--dialog-w`，内容多时用 `--dialog-w-wide`。
- 结构固定：**头**（标题 + 可选图标/状态 + 关闭）、**体**（唯一滚动区）、**尾**（左：危险操作或测试；右：取消 + 主按钮）。头尾不随内容滚动。
- 体内是两列表单：左列标签右对齐，右列控件。整行内容（表格、列表）跨两列。
- 分节：细线 + 小号灰色节标题，不用卡片套卡片。
- 「高级设置」用 `<details>` 折叠，默认收起；这是全站唯一允许的折叠位置。
- `Esc`、点遮罩、点关闭都会关闭；有未保存改动时先 `confirmDialog()`。弹框不嵌套（确认框除外）。
- 统一入口：`openDialog()` / `closeDialog()` / `confirmDialog()`，禁止原生 `confirm()` / `alert()`。

### 4.3 其它

- **按钮**：主按钮（`--accent` 实心）、普通、文字、危险（文字为 `--err`）。一个弹框或页头最多一个主按钮。
- **开关**：启用/停用用开关，不用复选框。复选框只用于多选。
- **芯片**：用于多选或筛选，选中用 `--accent-soft` 底 + `--accent` 字。
- **数据表**：仅在弹框内用于子项（Key、来源）。表头灰字无底色；操作列右对齐，最多「测试」+「···」。
- **时间**：统一走 `fmtTime()`：一分钟内「刚刚」，七天内「N 分钟/小时/天前」，更早显示日期。禁止浏览器默认格式。
- **空状态**：一句话 + 一个主按钮。
- **保存**：设置页有改动时底部浮出保存条（「N 项未保存 · 放弃 · 保存」），无改动时不显示。

## 5. 页面口径

### 5.1 供应商（效果图 01–03）

- 列表：logo + 名称；次要信息 = 预设版本 · 地址（异常时改为原因）；中间一列 **Key 健康条**（每把 Key 一小段，颜色同状态）+「N/M 可用」；状态；「被 N 个模型使用」。
- 详情弹框（宽）：启用开关、预设、接口地址 → **Key 池**（开关 / 标签 + 掩码 + 被引用数 / 状态 + 最近测试时间 / 测试 ···）。冷却中的 Key 在状态下方给「立即解除」。表格下方一行粘贴框，可一次粘贴多把（换行分隔）→ 高级：RPM 上限、每日重置、客户端 UA、供应商 ID（只读）。尾：左删除，右取消/保存。
- 添加供应商弹框：搜索 + 预设网格（logo、名称、协议）+ 末尾「自定义」；选中后下方出现名称、地址、Key；尾部主按钮「添加并测试」，左下「粘贴 cURL」。

### 5.2 模型（效果图 04–07）

- 列表：模型名；次要信息 = 首选来源（供应商 · 上游模型），多来源时加「另有 N 个备用」；状态；「N 个来源」。
- **添加模型**（一个窗口，不分步，不能在此新建供应商）：
  1. 来源：供应商下拉（只列启用且有 Key 的，显示可用 Key 数）。Key 用芯片：默认「任一可用」；点具体 Key 即取消「任一可用」，芯片显示点选序号；全部取消则回到「任一可用」；停用的 Key 不显示，冷却中的标黄可选。选了 2 把以上时出现「主备 / 轮询」分段（主备 = `sticky_failover`，轮询 = `round_robin`，写入路由的 `routing_strategy`）。下方一行灰字实时说明会生成什么。
  2. 模型：上游模型列表（带筛选、固定高度内滚动、复选可多选）；能力标签取 models.dev 目录，没有就不显示；已存在的标「已添加」并禁用；右上「重新拉取」「手动填写」（手动支持多个，换行分隔）；拉取失败只显示一句原因 + 手动填写。
  3. 对外模型名：选一个模型时为一个输入框，默认等于上游 ID；选多个时变为每个模型一行。与现有模型同名不报错，提示「将作为它的备用来源」，保存时并入。
  4. 思考档位：只在目录标记支持思考时出现，默认「跟随客户端」。
  5. 高级设置（折叠）：Key 回退（仅指定 Key 时出现，对应 `allow_key_fallback`，文案说明是 Key 被停用或删除时生效）、剥离思考、强制非流式、并发上限、权重（仅轮询时出现）。
  6. 尾部：左「测试」+ 摘要「已选 N 个模型 · 将生成 M 个来源」；右取消 / 添加模型。测试用第一个来源真实发一句「你好」，结果卡显示在体底部；测试期间禁用保存（沿用配置版本冲突纪律）。测试不是保存前提。
  7. 换供应商会清空已选 Key 和模型，已选模型时先确认。
  8. 保存成功：关闭弹框，列表滚到新行并短暂高亮。
- 编辑模型弹框：对外模型名、分流策略 → 来源表（拖动把手排序 / 供应商 / 上游模型 / Key 下拉 / 状态 / 测试 ···）+「添加来源」（复用添加模型的来源与模型控件）→ 高级折叠。

### 5.3 节点（效果图 08–09）

- 列表：名称；次要信息 = 角色 · IP · 最近同步（相对时间）；状态（在线 / 离线 / 宽限期内 / 待安装 / 已吊销）；同步次数。
- 详情弹框：名称、角色（分段）、租约与宽限、供应商范围与模型范围（芯片）→ 运行状态（只读两列：节点 ID、同步、配置版本、IP、Token 掩码 + 显示/复制、常用模型）。尾：左吊销 / 删除，右安装命令 / 轮换 Token / 保存。
- 一次性材料（安装命令、轮换后的 Token、后台密码）仍用单独弹框展示，只显示一次。

### 5.4 统计（效果图 10）与设置（效果图 11）

- 统计：顶部一条指标带（在线节点、节点累计调用与成功率、下发规模、配置同步），下方「模型使用分布」「节点分布」两张表。数据只来自节点上报，页头注明更新时间。
- 设置：左侧分组锚点，右侧行清单（标题 + 一行说明 | 控件）；改动后底部浮出保存条。

### 5.5 Full 独有页

概览、接入信息不出新效果图，按本文 token 与组件改造：KPI 用指标带，不用卡片阴影；接入信息的复制项用普通输入框 + 复制按钮。

## 6. 门禁（以测试为准，本文只列存在哪些）

保留：零内联样式、零抽屉、零彩色左边框、单文件体积上限、边缘包总字节上限。
新增：列表行唯一生成函数（§4.1）；JS / HTML 中不得出现 `px` 字面量；`app.css` 中除 `:root` 与暗色主题块外不得出现颜色字面量。
