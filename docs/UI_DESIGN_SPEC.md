# 控制台 UI 规范（v2.1）

> 适用：`shared/admin/` 这一份源码，同时服务 Hub 与 Full。
> **效果图是外观的唯一标准**：[`docs/ui-v2/mockups/`](./ui-v2/mockups/)，浏览器直接打开 `.html`。实现要和效果图一眼看上去一致；本文管结构、交互和不能做的事。
> 数值（颜色、尺寸、间距、字号）只在 `shared/admin/css/app.css` 的 `:root` 定义；组件里只用 `var()`。效果图的 `v2.css` 和 `app.css :root` 用同一套数值，二者不一致时改成一致，不另起一套。

## 1. 原则

1. **简约但不发白**：页面底是浅灰，内容放在圆角白卡片里；分组标题写在卡片外面（灰色小字）。不用阴影堆层次，只有弹框、浮层、提示有阴影。
2. **列表负责找，弹框负责改**：列表行不展开、不折叠；点行打开弹框。
3. **一个窗口做完一件事**：弹框内不分步；内容多时分节，次要项放进「高级设置」折叠（全站唯一允许折叠的地方）。
4. **能选就不让填**：有常用值的设置用分段选择 + 「自定义…」；有固定选项的用胶囊下拉。只有自由文本（地址、Key、名称）才用输入框。
5. **说明不常驻**：标签旁一个「?」，悬停或聚焦时弹出说明。行内只留标签本身。
6. **系统默认字体**，不用等宽字体；数字用 `tabular-nums`。
7. **只用现有数据**：不得引入后端没有的字段；要新字段先改契约（`AGENTS.md` §5）。
8. **不自行增减功能**：效果图和本文没有的控件不要加（例如 Key 表里的权重框），有的不要省（例如供应商行的健康条）。

## 2. 组件（外观以效果图为准）

| 组件 | 用途与规则 | 效果图 |
|---|---|---|
| 分组卡片 | 灰色组标题在卡片外；卡片内是行，行间细线。列表与设置都用它 | 01、11 |
| 列表行 | 只能由 `listRow()` 生成。列：头像 + 名称 / 次要信息 ｜ 附加列（可选）｜ 状态 ｜ 计数 ｜ 右箭头。各列宽度用 token，全站对齐。问题行的次要信息写原因（`--err` 色） | 01、04、08 |
| 首字头像 | 供应商不用 logo。取名称首字，按名称哈希从 8 组头像色（`--av-1-bg/fg` … `--av-8-bg/fg`，在 `:root`）中取一组；停用时灰度显示。同名永远同色 | 01、02 |
| Key 健康条 | 每把 Key 一小段横条，颜色同状态色，后跟「N/M 可用」 | 01 |
| 分段选择 | 灰色轨道 + 白色选中块。设置类数值给 3–4 个常用值，最后一段「自定义…」：点它把该段变成输入框，回车或失焦确认；当前值不在预设里时「自定义」段显示这个值并处于选中态 | 11 |
| 胶囊下拉 | 浅灰底圆角 + 右侧小箭头，点开是浮层菜单。禁止浏览器原生 `<select>` 外观 | 02、11 |
| 说明提示 | 标签旁「?」；悬停 / 聚焦显示白色浮层（标题 + 说明），离开消失；点击不跳转 | 12 |
| 开关 | 启用 / 停用。复选框只用于多选 | 02 |
| 芯片 | 多选与范围选择，选中为主色浅底 + 主色字 | 06、09 |
| 弹框 | 遮罩加模糊、居中。头（头像 / 标题 / 副信息 / 关闭）、体（唯一滚动区，左标签右控件）、尾（左危险或测试，右取消 + 主按钮）。**宽版**：供应商详情、添加供应商、编辑模型、添加模型；**窄版**：节点详情、确认框、一次性材料 | 02、03、05、06、09 |
| 保存浮条 | 设置页有改动时底部浮出「N 项未保存 · 放弃 · 保存」 | 11 |

其它：主按钮一个区域最多一个；时间统一 `fmtTime()`（刚刚 / N 分钟前 / 日期）；空状态一句话 + 一个主按钮。

## 3. 页面

导航顺序固定：Hub 为 **节点 / 供应商 / 模型 / 统计 / 设置**；Full 为 **概览 / 供应商 / 模型 / 接入信息 / 设置**。

### 3.1 供应商（01–03）

- 页头：标题 + 灰色摘要（个数 · Key 数 · 可用数）；右侧「测试全部 Key」+「添加供应商」。
- 工具条：搜索（名称、地址、Key 标签）+ 右侧分段筛选（全部 / 需要处理 / 已停用，带数量）。
- 列表按「需要处理 / 正常 / 已停用」分三张分组卡片，问题优先。行：首字头像、名称、地址或原因｜Key 健康条｜状态｜「N 个模型」｜箭头。
- 详情弹框（宽）：启用开关、预设（胶囊下拉）、接口地址 → Key 池（开关｜标签 + 掩码 + 被引用数｜状态 + 最近测试，冷却中给「立即解除」｜测试 ···），下方一行粘贴添加 → 限流与适配：RPM 上限（分段：不限 / 60 / 300 / 1000 / 自定义）、每日重置、客户端 UA、供应商 ID（只读）。
- 添加供应商弹框（宽）：搜索 + 预设网格 + 「自定义」；选中后出现名称、地址、Key；主按钮「添加并测试」。

### 3.2 模型（04–07）

- 列表：模型名｜首选来源（供应商 · 上游模型，多来源加「另有 N 个备用」）｜状态｜「N 个来源」。
- 添加模型（宽，一个窗口，不能在此新建供应商）：
  1. 来源：供应商胶囊下拉（只列启用且有 Key 的）；Key 芯片默认「任一可用」，点具体 Key 显示序号，全取消回到「任一可用」；≥2 把出现分段「主备 / 轮询」（`sticky_failover` / `round_robin`）；下方一行灰字说明会生成什么。
  2. 模型：上游列表，带筛选、固定高度内滚动、可多选；已存在的标「已添加」并禁用；「重新拉取」「手动填写」。
  3. 对外模型名（多选时每个模型一行；同名提示「将作为它的备用来源」）、思考档位（仅支持思考的模型）。
  4. 高级设置（折叠）：Key 回退（仅指定 Key 时）、剥离思考、强制非流式、并发上限、权重（仅轮询时）。
  5. 尾部：「测试」+ 摘要「已选 N 个模型 · 将生成 M 个来源」；取消 / 添加模型。测试期间禁用保存。
- 编辑模型（宽）：对外模型名、分流策略（胶囊下拉）→ 来源表（拖动排序｜供应商｜上游模型｜Key｜状态｜测试 ···）+「添加来源」→ 高级折叠。

### 3.3 节点（08–09）

- 列表：名称｜角色 · IP · 最近同步｜状态（在线 / 离线 / 宽限期内 / 待安装 / 已吊销）｜同步次数。
- 详情（窄）：名称、角色（分段）、租约（分段：1 小时 / 6 小时 / 24 小时 / 自定义）、宽限、供应商与模型范围（芯片）→ 运行状态（只读）。尾：左吊销 / 删除，右安装命令 / 轮换 Token / 保存。

### 3.4 统计（10）、设置（11–12）

- 统计：指标带 + 「模型使用分布」「节点分布」两张表，页头注明数据更新时间。
- 设置：左侧锚点导航；右侧分组卡片，每行「标签 + ?｜控件」。冷却、超时、并发一律分段选择 + 自定义；分流策略用胶囊下拉；说明全部进提示浮层，不留常驻说明文字和提示框。

### 3.5 Full 独有页

概览、接入信息沿用同样的分组卡片、分段、胶囊下拉与提示规则。

## 4. 落地与验收

1. 落地一律走 PR，不直接推 main、不发版；PR 描述贴每个改动页面的截图（浅色、1280 宽，列表与弹框打开态各一张）。
2. Hark 拉分支构建，用模拟数据逐页截图，与效果图左右对比，按下面清单逐条判定；全部通过后才合并、才发版。
3. 验收清单：
   - [ ] 导航顺序与 §3 一致
   - [ ] 列表全部来自 `listRow()`，各页列对齐；供应商行有首字头像、健康条、模型数
   - [ ] 页面底浅灰、内容在分组卡片里，组标题在卡片外
   - [ ] 没有浏览器原生下拉外观；设置类数值是分段 + 自定义
   - [ ] 没有常驻长说明，说明都在「?」提示里
   - [ ] 弹框宽窄与 §2 一致；头尾不随内容滚动；Esc / 遮罩 / 关闭可用，有改动先确认
   - [ ] 列表里没有展开 / 折叠；折叠只在弹框的「高级设置」
   - [ ] 没有效果图以外的新控件，也没有少掉效果图里的元素
   - [ ] 颜色只在 `:root` 与暗色块；JS / HTML 无尺寸数字；时间经过 `fmtTime()`
   - [ ] `npm run check` 通过

## 5. 门禁（以测试为准）

零内联样式、零抽屉、零彩色左边框、单文件体积上限、边缘包总字节上限、列表行唯一生成函数、JS / HTML 无 `px` 字面量、颜色只在 `:root` 与暗色块。
